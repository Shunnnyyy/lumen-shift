System logic

How the Lighting System Decides

Input Hour + motion + street flow
Controller Adaptive dimming rule
Output Brightness + energy saved

Sensor layer

PIR or ultrasonic detection estimates whether a pedestrian, bike, or vehicle is passing through a low-activity street segment.

Control layer

The system keeps a safe base dim level, then raises brightness only when movement and nighttime conditions justify more power.

Impact layer

Estimated energy savings compare adaptive brightness against a fixed always-on baseline, turning the visual simulation into a measurable EE concept.

Arduino Build Plan

Parts

Hardware

Arduino Uno, PIR sensor or ultrasonic distance sensor, LED strip or high-brightness LEDs, resistor, breadboard, and jumper wires.

Signal

Input to PWM

Read movement from the sensor, smooth the signal, then use PWM output to fade LEDs between base dim and active brightness.

Evidence

Testing

Compare fixed brightness against adaptive brightness across simulated quiet, moderate, and high-activity street conditions.
